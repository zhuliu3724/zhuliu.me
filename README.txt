Quick GitHub Pages deployment:
1. Create a GitHub account (for example username: zhuliu).
2. Create a PUBLIC repository named exactly: <username>.github.io
3. Upload all files and folders in this package to the repository root.
4. Commit the files.
5. Open Settings > Pages and confirm deployment from the main branch/root.
6. After GitHub publishes it, your site will be available at:
   https://<username>.github.io/
